# 黔货出海 · 视频工作站（station）

> 这是与 [`demo/`](../demo/index.html) **并列**、**独立可运行**、**互相链接** 的工作站应用。
> 它把 [`video/output/黔货出海·都匀毛尖_Demo演示视频.mp4`](../video/output/黔货出海·都匀毛尖_Demo演示视频.mp4)
> 这部成片包装成 NLE（Non-Linear Editor）形态 —— 评委/团队打开即可看到项目元数据、
> 镜头清单、播放器、时间线与跳转能力。

## 一、运行方式

工作站在浏览器里运行。**必须用 HTTP 服务**（不要直接双击 `index.html`），
原因是成片 mp4 与源 Demo 的关联链接要走 `../demo/...` `../video/...` 这种相对路径，
`file://` 协议下会失败。

### 推荐：从项目根目录起服务（一份服务同时跑两套系统）

```bash
# 在项目根目录 D:\黔货出海\ 下执行
python -m http.server 8899

# 然后浏览器打开
#   http://127.0.0.1:8899/station/index.html   ← 工作站
#   http://127.0.0.1:8899/demo/index.html      ← 源 Demo
```

### 也可：仅起工作站服务（仅这一个 app 可见）

```bash
cd station
python -m http.server 8765
# http://127.0.0.1:8765/index.html
```

> 此时工作站会通过 `../../video/...` 这条相对路径依然能加载到成片（`videoCandidates` 已写好兜底）。

## 四、交互速查

| 动作 | 方式 |
| --- | --- |
| 播放 / 暂停 | `K` 或 `空格`，或中央 ▶ 按钮 |
| 倒退 / 快进 5 秒 | `J` / `L` |
| 上一镜 / 下一镜 | `←` / `→`，或传输栏 ⏮/⏭ |
| 跳到片头 / 片尾 | `Home` / `End` |
| 跳到第一/二/三幕 | 数字键 `1` / `2` / `3`，或底部"跳到幕"按钮 |
| 镜头跳转 | 项目浏览器点击镜头 / 时间线点击块 |
| 搜索镜头 | 项目浏览器顶部搜索框（如「成本」「物流」） |
| 倍速 | 0.5× / 1× / 1.5× / 2× |
| 音量 | 传输栏底部音量条 |
| 项目元信息 | 右下角 `i` 圆形按钮（模态浮窗） |

## 五、数据来源

`assets/js/data.js` 是自动生成的，运行：

```bash
python _build_data.py
```

会从 `../video/shots_script.py` 读取全部镜头元数据（标题、画面动作、旁白文稿），
再按播放顺序算出 `t_in / t_out`，最终输出 23 段（含片头/片尾）+ 项目元数据。

> 修改分镜后**先改 `video/shots_script.py`**，再跑 `_build_data.py`，再 `python video_gen.py` 出片，
> 最后刷新 `station/` 即可看到全部同步。
> 工作站、源 Demo、成片三者构成一个闭环。

## 六、与源 Demo 的关系

两个系统独立运行又相互关联：

| 入口 | 目标 |
| --- | --- |
| 顶栏 "打开源 Demo" | `../demo/index.html`（新窗口） |
| 顶栏 "查看分镜文档" | `../docs/演示视频分镜脚本与旁白文稿.md`（新窗口） |
| 顶栏 "下载成片" | `../video/output/黔货出海·都匀毛尖_Demo演示视频.mp4`（新窗口） |
| 元数据面板"关联交付物" | 5 个直达：源 Demo、分镜文档、分镜源代码、视频生成代码、项目 README |

视频源通过 `videoCandidates` 自动探活（`../...` → `../../...` → `/...`），
无论服务从 `station/` 还是项目根起都能找到。

## 七、开发工具

### 跑全套截图

```bash
python _capture.py
# 产物：station/_shots/*.png  —— 01~08 全场景，09~10 两系统独立运行
```

### 重新生成数据层

```bash
python _build_data.py
# 写入 station/assets/js/data.js
```

### 单镜头视频快速出片（与工作站共享 shots_script.py）

```bash
cd ../video
python video_gen.py --only 02            # 只生成第 2 镜
python video_gen.py                       # 全量出片
```
