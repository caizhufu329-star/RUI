# 📄 简历工坊 — 个性化简历编辑器

纯前端 HTML 简历编辑器，浏览器打开即用。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

## ✨ 功能

- 🎨 **8 套模板**：经典蓝、深色商务、清新绿、暖阳橙、玫瑰红、星空紫、海洋蓝、森林绿 + 自定义配色
- ✏️ **点击编辑**：点击任意文字/图标直接修改，实时预览
- 🖼️ **头像上传**：支持上传个人头像
- 📤 **多格式导出**：一键导出 PDF (A4)/JPG/Word
- 💾 **自动保存**：编辑内容保存到浏览器本地，刷新不丢失
- 📱 **响应式**：适配电脑和手机

## 🚀 使用

下载 [`index.html`](index.html)，用浏览器打开即可开始编辑。

或启用 **GitHub Pages**：Settings → Pages → 选 `master` 分支 → Save → 访问 `https://你的用户名.github.io/resume-editor/`

## 🧰 技术

纯前端，零依赖安装。html2canvas + jsPDF（CDN 引入）+ Font Awesome 图标库。
